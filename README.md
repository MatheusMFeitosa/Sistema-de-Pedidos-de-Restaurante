# Só Burgão - Sistema de Pedidos

Projeto acadêmico de um cardápio digital interativo e carrinho de compras para restaurante. O sistema foi construído aplicando conceitos de Programação Orientada a Objetos (POO) e manipulação de DOM utilizando exclusivamente tecnologias nativas da web.

## Funcionalidades

- **Carrossel de Destaques:** Navegação automática e manual pelos pratos do restaurante.
- **Cardápio Interativo:** Listagem dinâmica dos produtos disponíveis.
- **Carrinho de Compras:** Adição de itens, controle de quantidade, cálculo em tempo real de subtotal e taxa de entrega (Delivery/Retirada).
- **Modo Administrador (Login Simples):** Área restrita protegida por senha para realizar o CRUD (Criar e Deletar) dos pratos do cardápio.
- **Persistência de Dados:** Uso do `localStorage` para salvar o cardápio e os pedidos no navegador.

## Tecnologias Utilizadas

- **HTML5:** Estrutura semântica do projeto.
- **CSS3:** Estilização com CSS Flexbox, Grid Layout e variáveis nativas (sem o uso de frameworks).
- **JavaScript (Vanilla JS):** Lógica do sistema utilizando Funções Construtoras para POO e manipulação limpa do DOM.
